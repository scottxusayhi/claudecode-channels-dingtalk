钉钉多租户 Claude Code · 架构

一个钉钉企业内部机器人作入口；白名单里的每个人，都有一个自己的、相互隔离的 Claude Code 会话。

1 条连接只有 broker 连钉钉；同一 AppKey 多连接会被网关随机分流
1 人 1 会话后台会话 + 私有工作空间，按需启动、空闲停止、续上原对话
7 层隔离从钉钉可见范围到 OS 沙箱，见第 3 节
≈5.5 秒冷启动到回复（实测）；会话在线时 3–5 秒

1. 进程与模块

组件文件职责

协议与配置shared.ts状态路径、配置解析（含 tenants 块）、broker↔shim 的换行分隔 JSON 协议。

2. 用户说「hello」之后

以用户B的会话已停止（空闲后被结束）为例；右侧橙色时间取自日志里第一次冷启动的实测。

  • 为什么要等握手再 +1 秒（⑭）：Claude Code 在 MCP 握手后才注册 channel 处理器，之前到达的通知会被静默丢弃 —— 真机上第一条消息丢过，这一步就是为此加的。
  • 为什么校验 sessionId（⑮–⑯）：claude --bg 自己分配会话 id；shim 上报的 CLAUDE_CODE_SESSION_ID 必须以 broker 启动时拿到的短 id 开头，冒充别的租户会被拒绝并断开。
  • 出错时：启动失败或 90 秒内没连上 → 回复TA「会话启动失败」并停掉半成品；同时在线会话超过上限 → 回复「会话已满」；钉钉回调里没有 staffId 的外部联系人 → 丢弃。
  • 引用回复与附件：被引用的那条以引用块放在消息前面；附件下载到TA工作空间的 attachments/，路径随消息一起给会话。

3. 隔离：一层一层

层谁来执行挡住什么
钉钉可见范围 + access.json 白名单钉钉平台 / broker不在范围内的人发不进来；不在白名单的私聊被静默丢弃，不暴露机器人存在。
--restrictedClaude Code不读用户 / 项目 / 本地任何设置文件（你的 bypassPermissions 不继承，租户改 settings 无效）；文件工具限制在工作空间；自带的 auto-memory 也被关闭。
--tools 白名单 + dontAskClaude Code没有 SendMessage / ListAgents（借你的会话越权）、Skill、Cron 等；任何需要确认的操作直接拒绝。
OS 沙箱（macOS Seatbelt）操作系统Bash 只能读自己的工作空间和工具链、只能写工作空间、不能联网、连不上 broker socket、看不到进程列表。实测：其他租户、~/.claude、~/.ssh、人设目录全部 BLOCKED。
broker 强制broker会话身份按 sessionId 校验；只能回复自己用户的私聊；不能改路由、不能用管理接口；求助只能发给 escalateTo 里的人，每小时最多 5 次。
会话间通信与连接器Claude Code 设置crossSessionInbound: refuse；不加载你 claude.ai 账号的连接器。
提示词放在租户够不着的地方文件布局人设和拼好的提示词在状态目录（0600），记忆在各自工作空间；文件名映射是单射，两个人不会共用。实测两个租户互相问不出对方人设。

所有租户与你是同一个 OS 用户，以上是层层设防而不是硬隔离；租户能问出自己的人设和记忆。

5. 生命周期

  • 首条消息：建工作空间 → 拼提示词 → claude --bg 启动 → shim 连上并通过校验 → 冲刷排队的消息。
  • 空闲：Claude Code 会在约 1 小时无活动后结束后台会话（实测）；broker 自己的 idleMinutes 回收是第二道。
  • 再来消息：--resume 续上同一段对话；若旧会话还没退干净，Claude Code 会续写成一个副本，broker 记下新 id 并清掉旧的。
  • 人设与记忆：每次启动时读入（--system-prompt-snapshot off 让续上的对话也拿到新版本）；会话运行中自己往 MEMORY.md 记东西，下次启动时带回。
  • 连接：每 20 秒 ping；45 秒没有 pong 就判定连接已死并重连 —— 实测换网络后 53 秒内自愈。
  • 求助：会话做不了的事用 ask_owner 发到你的私聊；单向，你在钉钉里的回复进的是你自己的会话。

6. 已知限制

  • 同一个 OS 用户下的纵深防御，不是容器级隔离；不完全信任的租户应换成容器或独立 OS 用户。
  • 所有租户共用你的 Claude Max 额度；可以用 tenants.model 让租户用更便宜的模型。
  • broker 还没有 launchd 托管：机器重启后不会自己起来，笔记本休眠时机器人离线 —— 计划迁到 Mac mini。
  • Channel 仍是 Claude Code 的 research preview；MCP SDK 锁在 1.29.0，以免新协议版本静默关掉 channel 推送。
  • 群聊不在租户模式内，仍按 /dingtalk:bind 绑定到某个会话。
